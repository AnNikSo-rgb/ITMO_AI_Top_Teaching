# Требования к программному и техническому обеспечению для выполнения проекта


Для выполнения проекта студенту необходим компьютер, на котором можно запускать Python-код, работать с Jupyter Notebook и хранить проект в Git-репозитории.

### Минимальные технические требования

- персональный компьютер или ноутбук;
- 64-разрядный процессор;
- не менее 8 ГБ оперативной памяти;
- не менее 2 ГБ свободного места на диске для среды разработки, библиотек, данных и результатов;
- стабильное подключение к интернету для установки программ, загрузки зависимостей и работы с удалённым Git-репозиторием.

Использование графического процессора не требуется. Все расчёты проекта должны выполняться на обычном центральном процессоре.

### Операционная система

Допускается использование:

- Windows;
- macOS;
- Linux.

Выбранная операционная система должна поддерживать установку Python, Jupyter и Git.

### Обязательное программное обеспечение

Студенту должны быть доступны:

1. **Python версии 3.10 или выше.**
2. **Jupyter Notebook или JupyterLab** для выполнения и сохранения ноутбуков.
3. **Git** для получения и отправки файлов проекта в удалённый репозиторий.
4. **Веб-браузер** для работы с Jupyter, GitHub, GitLab или другой платформой размещения репозитория.
5. **Редактор текста или среда разработки**. Допускается использовать Visual Studio Code, PyCharm, JupyterLab либо другой инструмент с поддержкой Python и Jupyter Notebook.
6. **Средство просмотра PDF-файлов** для проверки итогового отчёта и презентации.

Допускается выполнение проекта в облачной среде, например Google Colab, JupyterHub или GitHub Codespaces, если она позволяет установить необходимые библиотеки, сохранить результаты и загрузить итоговые файлы в Git-репозиторий.

### Необходимые библиотеки Python

Для выполнения обязательной части проекта необходимы:

- `numpy` — численные расчёты;
- `pandas` — загрузка, преобразование и анализ табличных данных;
- `scipy` — статистические распределения, критерии и интервальные оценки;
- `statsmodels` — статистические модели, оценки коэффициентов и анализ результатов;
- `scikit-learn` — подготовка данных, линейные и логистические модели, регуляризация и расчёт метрик;
- `matplotlib` — построение графиков;
- `seaborn` — дополнительная визуализация данных;
- `jupyter` или `jupyterlab` — выполнение ноутбуков.

Для байесовского этапа достаточно средств `numpy`, `scipy` и `matplotlib`. Использование специализированных библиотек байесовского моделирования не является обязательным.

Рекомендуемый файл `requirements.txt`:

```text
numpy>=1.24
pandas>=2.0
scipy>=1.10
statsmodels>=0.14
scikit-learn>=1.3
matplotlib>=3.7
seaborn>=0.12
jupyterlab>=4.0
```

Допускается использование более новых совместимых версий библиотек.

### Рабочая среда

Рекомендуется создать отдельное виртуальное окружение проекта. Например:

```bash
python -m venv .venv
```

Активация в Windows:

```bash
.venv\Scripts\activate
```

Активация в macOS и Linux:

```bash
source .venv/bin/activate
```

Установка зависимостей:

```bash
python -m pip install --upgrade pip
pip install -r requirements.txt
```

Студент должен убедиться, что все ноутбуки проекта запускаются в чистом окружении после установки библиотек из `requirements.txt`.

### Доступ к материалам и сервисам

Студенту должны быть предоставлены:

- индивидуальный набор данных в формате CSV;
- постановка задач по этапам проекта;
- ссылка на шаблон или требования к структуре репозитория;
- доступ к GitHub, GitLab или другой согласованной платформе;
- доступ к учебным материалам дисциплины;
- сроки сдачи отдельных этапов и итогового проекта.

Преподавательские метаданные, скрытые параметры генерации и исходные значения, не входящие в студенческий набор данных, студенту не предоставляются.

### Требования к воспроизводимости

Проект должен запускаться на другом компьютере после:

1. клонирования Git-репозитория;
2. создания виртуального окружения;
3. установки зависимостей из `requirements.txt`;
4. последовательного выполнения ноутбуков.

Абсолютные пути к локальным папкам студента использовать нельзя. Все пути к данным и результатам должны быть относительными и работать внутри структуры репозитория.
